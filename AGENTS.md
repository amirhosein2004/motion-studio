## Always-on consent rules

- **No video export before approval.** Do not create any video file — test or low-resolution review outputs included — until the user explicitly approves the viewed version and requests that export. Interactive previews, stills, and code review are allowed at any time.
- **No synthetic voice.** Never generate, clone, or convert the user's voice; the user records their own narration. Visible subtitles, background music, and SFX also require explicit authorization.

## Contract

- Explicit user requirements take precedence over workspace defaults and skill recommendations, subject to platform and safety rules.
- Documentation changes apply to new work. Preserve existing projects, source assets, exports, and approved styles; migrate or redesign older work only on an explicit request.
- Shared documentation is English. Educational content, teacher guides, and Persian on-screen copy stay natural Persian; follow [rules/persian-rtl.md](rules/persian-rtl.md) for all Persian text and UI.
